# Транскрибатор

Небольшое локальное приложение: M4A / MP4 / MP3 → текстовый файл UTF-8. Интерфейс на русском, перетаскивание файла, выбор языка и модели, прогресс, редактирование текста, необязательные временные метки и скачивание TXT.

## Запуск на Windows

1. Установите **Python 3.12** с https://www.python.org/downloads/ (с Python Launcher).
2. Распакуйте проект в обычную папку.
3. Откройте `start.bat`. Он создаст виртуальное окружение, установит зависимости и откроет приложение по адресу http://127.0.0.1:8501.
4. Выберите файл, нажмите «Распознать запись», затем «Скачать TXT».

Первый запуск требует интернета для зависимостей и модели. Уже скачанная модель работает локально. Аудио не отправляется в сервис распознавания. Отдельная установка FFmpeg не требуется: декодирование выполняет PyAV из зависимостей faster-whisper.

## Ручной запуск (Windows / Linux / macOS)

Работайте из папки проекта. Рекомендуется Python 3.12.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / macOS:
# source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Настройки и ограничения

- `small` — исходный вариант; `base` быстрее; `medium` и `large-v3` точнее, но значительно тяжелее на CPU. Скорость зависит от компьютера, длительности и модели.
- По умолчанию язык определяется автоматически; для коротких записей полезно выбрать язык вручную.
- Обрабатывается один файл до 500 МБ. Это лимит загрузки, а не гарантия достаточности RAM: декодированный звук длинной записи занимает больше памяти. Очень длинные записи лучше разделить.
- Для MP4 нужна аудиодорожка; при нескольких дорожках распознаётся первая.
- Выполняется транскрипция на исходном языке, без перевода и разделения по говорящим.
- Переключение временных меток восстанавливает исходную версию текста, сбрасывая ручные правки. Смена файла, языка или модели сбрасывает результат.
- Текст хранится в памяти сессии; сохраняйте результат через «Скачать TXT» перед закрытием страницы. Временный файл автоматически удаляется после успеха или ошибки.
- Приложение слушает только `127.0.0.1`. Не публикуйте его в интернет без отдельной настройки авторизации и ограничений ресурсов.

## Структура

`app.py` — интерфейс; `transcribe.py` — обработка и форматирование; `tests/test_transcribe.py` — проверки обработки входа, результата и ошибок; `.streamlit/config.toml` — локальный адрес и оформление.

Проверки без скачивания моделей:

```bash
python -m unittest discover -s tests -v
```

Технологии: [Streamlit](https://docs.streamlit.io/) и [faster-whisper](https://github.com/SYSTRAN/faster-whisper).
